# CodePilot

> Understand your codebase with AI.

Plataforma web de análise inteligente de repositórios GitHub, combinando
análise determinística (Haskell) com análise por IA (Python + LLM).

## Status

🚧 Em desenvolvimento — Fase 1: estrutura base.

## Stack

- **Frontend:** React + TypeScript + Vite + Tailwind CSS
- **Backend:** Node.js + TypeScript + Express
- **IA:** Python + FastAPI (fase futura)
- **Análise determinística:** Haskell (fase futura)
- **Banco:** PostgreSQL / Supabase (fase futura)

## Como rodar (dev)

```bash
npm install
npm run dev:backend
npm run dev:frontend
```

Frontend: http://localhost:5173
Backend: http://localhost:3001/api/health
